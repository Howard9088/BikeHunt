# BikeHunt 同款多渠道比价方案（按用户补充要求修订）

日期：2026-10-14。用户补充：采用 `E:\项目开发\网络爬虫应用目录` 的 Scrapling v0.4.15；首页默认采用类似抖音的上下滑动商品图库，同时保留平铺图库选择。

## 1. 产品行为

上下滑动看商品（手机触摸、电脑滚轮）→ 点击比价 → 选择具体规格 → 查看同款各渠道报价 → 查看原币价、人民币商品价、运费、税费与核实状态 → 跳转第三方商品页。支持切换平铺图库，并记住浏览偏好。

BikeHunt 提供信息与外链，不实现购物车、支付、订单、物流或售后。README 与原聊天最终定位优先于旧《01_技术实现要求.md》中涉及交易的内容。

## 2. 模块与职责

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 数据契约 | `app/catalog/models.py` | 商品规格、报价、核实证据、汇率快照、比较结果；金额采用 Decimal |
| 采集 | `app/collectors/`、`scripts/collect_offers.py` | 固定 Scrapling v0.4.15，Fetcher 静态抓取，按站点配置使用 DynamicFetcher 渲染；Selector 解析公开数据；robots 检查、限频、3 次指数退避、Loguru 日志、原始证据及最后成功快照 |
| 比价 | `app/catalog/service.py` | 严格同款匹配、统一汇率换算、可购买条件校验、完整成本排序、降级与缺失原因 |
| 页面与路由 | `app/main.py`、`web/index.html` | 默认一屏一商品的垂直 scroll-snap 图库，可切换平铺视图；沿用搜索与侧栏比价路径，由后端提供唯一比较结果 |

采集与查询分开：查询读取本地最后成功快照，不在每次搜索时发起多站网络请求。单个来源失败不删除其他来源或覆盖其有效历史快照。

资料目录仅作框架、示例和版本依据。依赖及业务代码、日志、抓取数据均放在 BikeHunt；不修改 Scrapling 归档或混用上游新版本 API。商品采集直接用 Scrapling，不依赖搜索摘要填价格。

## 3. Interface 与 Schema（Type Hints）

```python
from datetime import datetime
from decimal import Decimal
from typing import Literal, Protocol
from pydantic import BaseModel

CheckStatus = Literal["yes", "no", "unknown"]

class Evidence(BaseModel):
    status: CheckStatus = "unknown"
    url: str | None = None
    checked_at: datetime | None = None
    note: str = ""
    scope: Literal["site", "offer"] = "offer"

class Money(BaseModel):
    amount: Decimal  # 非负有限数；单位：对应 currency 的货币元
    currency: str    # ISO 4217 三位币种代码

class ProductIdentity(BaseModel):
    brand: str
    model: str
    gtin: str | None = None
    mpn: str | None = None
    size: str | None = None
    color: str | None = None
    year: str | None = None
    gender: str | None = None

class Offer(BaseModel):
    offer_id: str
    source_code: str
    identity: ProductIdentity
    name: str
    url: str
    image: str | None = None
    price: Money
    shipping: Money | None = None  # None 为未知；明确免运费才使用 0
    tax: Money | None = None       # None 为未知；明确税费为 0 才使用 0
    stock: Literal["in_stock", "out_of_stock", "unknown"] = "unknown"
    shipping_to_china: Evidence
    china_issued_card: Evidence
    fetched_at: datetime | None = None
    data_kind: Literal["live_snapshot", "legacy_cache"]

class FxSnapshot(BaseModel):
    snapshot_id: str
    rate_date: str
    fetched_at: datetime
    rates: dict[str, Decimal]  # 1 原币货币元对应多少人民币元
    stale: bool

class ComparedOffer(BaseModel):
    offer: Offer
    product_cny: Decimal | None
    shipping_cny: Decimal | None
    tax_cny: Decimal | None
    total_cny: Decimal | None
    eligible: bool
    reasons: list[str]
    fx_snapshot_id: str

class ProductComparison(BaseModel):
    product_id: str
    identity: ProductIdentity
    offers: list[ComparedOffer]
    recommended_offer_id: str | None
    fx: FxSnapshot

class OfferCollector(Protocol):
    def collect(self, urls: list[str]) -> list[Offer]:
        """采集公开商品页；失败记日志并保留上次成功快照。"""

class ComparisonCatalog:
    def search(self, query: str = "") -> list[ProductCard]: ...
    def compare(self, product_id: str,
                variant_id: str | None = None) -> ProductComparison: ...
```

## 4. 不变量与排序

1. **同款匹配**：优先合法 GTIN，其次品牌＋制造商型号＋规格；尺码、颜色、年份和性别冲突必须分开。不能把商家 SKU 直接当跨站型号；缺少可靠标识时保留为独立商品，不根据相似标题自动合并。目录可以聚合型号，但详情报价必须按相同规格比较。
2. **准入**：直邮中国有确认依据；支付接受有证据的 Visa、Mastercard 等国际卡种，且商家没有禁止中国发卡的明确限制。依照用户补充，不按发卡银行名称设白名单；商家接受卡种与银行实际授权分别显示。库存可买、价格未过期、汇率有效，才可成为推荐候选。品牌区域限制及 marketplace 卖家配送需报价级核实。
3. **成本**：所有报价使用同一汇率快照。总成本＝人民币商品价＋人民币运费＋人民币税费；任一项未知则总成本为 None，并显示缺项。运费/税费已含在商品价中时需依据并避免重复相加。
4. **推荐**：完整、已核实且可购买的报价按总成本升序；不完整报价另列为“待核实”，不参与最低到手价推荐。缺失币种汇率、过期缓存、售罄与未验证渠道不得推荐。不得将演示或 Mock 数据放入生产目录。
5. **可追溯**：显示原币价、人民币参考价、来源链接、采集时间、汇率日期、缓存状态与待核实原因。金额为人民币元，参考汇率不保证信用卡实际入账金额。

## 5. 首批接入与接口

已用 Scrapling 实测 MAAP、Team Cycles、Sigma Sports，robots 对本轮商品页允许访问且 HTTP 200。首批采集 MAAP Archive 列表及 Evade 2.0 黑色/Antarctica 详情、Team Cycles 同款黑色详情、Sigma Sports 同名多规格 JSON-LD。

MAAP 与 Team Cycles 以公开制造商代码 `MAP-MAJ339_BLK` 和选定 XS SKU 对齐。Sigma 的商家编号不冒充制造商型号，缺少跨站标识的记录独立展示。MAAP 原价币种标签与现价不同的记录不计算折扣；Sigma 的 GB 运费不作 CN 运费。

目录 Schema 增加 ProductCard（商品入口）、VariantChoice（尺码）、reference_stock/fetched_at；同颜色不同尺码呈现一张卡，详细比较仍逐规格进行。

Amazon US/UK/DE/JP 保留来源登记，明确显示“尚未接入商品数据”；只有取得适用的官方商品数据接口授权与真实响应后才标记已接入。

新增 `GET /api/catalog?q=` 和 `GET /api/catalog/{product_id}?variant_id=`，保留原有 `/api/products`、`/api/sources`、`/api/fx`；来源接口增加数据接入状态。页面搜索与侧栏使用同一后端比较结果。

## 6. 验收

独立 `tests/test_catalog.py` 使用 Mock 报价验证同款与异规格隔离、跨币种排序、零元与缺失成本的区别、未知卡/配送/库存、过期报价/汇率、来源失败隔离与异常数值。

独立采集测试使用公开 JSON-LD 的 Mock HTML 验证解析、限频、重试上限和禁止抓取路径。生产数据只写实际取得的商品信息。

启动本地 18888 服务，核对健康接口、目录/详情接口、真实同款双渠道报价、桌面与手机搜索及侧栏。真实渠道不满足推荐条件时，应显示已发现报价及明确缺项，而不是制造推荐。
