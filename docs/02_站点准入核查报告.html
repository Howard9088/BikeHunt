1.4 核心结论

  1. 跨境 DDP 只有一家。对大陆买家，能用官方原文证明「结账即预收进口税（多退少不补）」的骑行类渠道只有亚马逊海外购一家；其余全部为到岸缴税或不可达。该渠道电脑端已不能下单（2024-01-27 起），只能走 App / 微信小程序，且整车未见于海外购清单。
  2. 没有一家海外品牌官网同时被官方证实「可直邮中国 + 中国卡 + DDP 预收」。海外直邮的税负主流是到岸缴税；DDP 机制存在但中国可达性多未落地的有 INEOS Grenadiers（可选预付）、Sigma Sports（可选预付）、Velocio、Ribble Cycles。
  3. 整车不存在合规的跨境直邮个人通道。Cannondale 明文不发货美加以外、Trek 明文不接受转运地址、Orbea 强制经销商自提、Colnago 整车门店自提或厂方交付、Cube 零直销、Buycycle 配送国清单不含中国。唯一现实通路是品牌中国区官渠（Canyon 中国站 / Specialized 中国官网 / 捷安特中国商城）与欧盟整车品牌直邮 + 到岸缴税（Rose Bikes 官方配送国清单含 China）。
  4. 税负口径已换代。行邮综合税率现为三档 13% / 20% / 50%，自行车、骑行服、运动用品均落 20%；旧「2019 年版归类表 / 完税价格表」已废止不得再用；免税额是应征税额 ≤ 50 元（约对应 20% 档下 250 元以内存量商品），与「每次限值 2000 元」是两个不同概念。整车入境唯一现实口径是单件不可分割 + 个人自用的资金邮路径。
  5. 硬红线两条。① 旧衣物（HS 6309000000）在《禁止进口固体废物目录》内，属禁止进口货物，二手 / 古着骑行服不得提供跨境链路；② 成人非电动自行车整车不在 CCC 目录，可正常入境，但电动助力车、锂电类器材（0914/0915）在 CCC 目录内，须逐 SKU 判定。
  6. 采集侧结论。robots 最宽松、商品页可直抓的站点集中在德国与荷兰（Radon 全站 Allow、Bike24 商品页可抓、R2-Bike、Bike-Components）；英国 / 美国大站反爬最强（亚马逊、eBay、Wiggle 系已消失）。22 个域名本轮 robots 未能取得，一律按「未查到」处理，不得默认可爬。

02判定基准

上游五份调研文件的判定口径互不一致（有的把「税负是否为 DDP」计入判定、有的只看官方 payment 页），本章统一口径，第 3 章据此重新推导，并在第 3.3 节列出全部重判差异。

2.1 四档判定规则（唯一口径）

判定成立条件本项目含义
合格 官方依据同时证实两条：① 可用国际信用卡（无排除中国发卡行的条款）；② 可发货至中国大陆。 可直接接入，无需实单验证即可按「可付 + 可直邮」设计链路。
有条件合格 上述两项成立，但：支付侧存在官方明示的中国卡风控 / 风控提示；或其中一项仅有间接依据（官方文本未点名中国、但也不含排除性条款）。 可接入，但必须实单验证一次；报错与风控话术要单独准备。
不合格 官方明文排除中国大陆；或该域名 / 商城已不存在；或明确不对个人跨境销售。 不接入，或只作为「境内官渠 / 比价参照」存在，不承担跨境链路。
未能证实 上述两项中任一项无任何官方依据、无法判断。 不排除将来可用，但当前不得写成既有事实，只能列入观察名单。
证据分级（判定时按此取用）
  • 官方证实＝站点自身官方页面的原文（配送政策页、帮助中心、条款、支付/结账页、robots.txt）。
  • 间接依据＝官方文本声称全球配送 / 区域档位（如「Rest of the World」「International」）但未点名中国，且不含任何排除中国的条款；或由中国方向以外的机构官方发布、指向该站的材料（如银联国际新闻稿）。
  • 无依据＝本轮未取得任何官方文本（未抓到 / 被 robots 拒绝 / 页面不存在该条目）。一律记「未能证实」，不得由机制推断肯定结论。
与上游口径的差异（本报告的统一化处理）：上游第 4、5 号文件把「税负是否为 DDP」作为第二条硬标准，导致部分站点仅因「到岸缴税」被降级。本报告按统一规则判定，「DDP 预收 / 到岸缴税 / 必须转运」剥离为独立一列，只影响推荐优先级，不影响判定档位。
