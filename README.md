# BikeHunt 全球骑行好价

> BikeHunt 是一个全球骑行商品信息聚合与比价网站。
> 我们只做“信息搬运 + 结构化整理 + 人民币比价 + 购买路径判断”，不参与交易。

创建时间：2026-10-14

项目目录：`E:\项目开发\BikeHunt`

---

## 1. 一句话定位

**用户只需要一张支持境外支付的中国信用卡，BikeHunt 帮他找到：这个商品在哪里能买、哪里更便宜、预计人民币要花多少钱。**

最终交易始终在第三方网站完成。

BikeHunt：
- 不收款
- 不代付
- 不代下单
- 不持有库存
- 不处理订单
- 不处理物流
- 不处理售后
- 不保存用户用于购物的银行卡信息

---

## 2. 核心使用逻辑

用户不需要先选网站。

正确流程是：

```
找商品
→ BikeHunt 搜索全球同款
→ 排除不能直邮中国的渠道
→ 核对商家支持的卡种和中国发卡限制（境外支付卡仍需银行实际授权）
→ 外币价格统一换算成人民币
→ 叠加已知运费与税费
→ 按预计总成本从低到高排序
→ 用户点击外链
→ 在第三方网站自行完成交易
```

**商品是入口，网站只是渠道。**

## 4. 用户看到的核心信息

每个商品统一展示：

- 商品名称 / 品牌 / 型号
- 商品图片
- 原币价格
- 人民币参考价格
- 原价 / 折扣价 / 折扣率
- 尺码与库存
- 是否直邮中国
- 中国大陆发行信用卡是否可用
- 国际运费
- 税费
- 预计人民币总成本
- 数据更新时间
- 第三方商品页面链接

人民币换算使用统一汇率快照，避免不同网站之间直接拿不同外币数字比较。

---

## 5. 排序原则

推荐渠道必须先满足：

1. **能直邮中国**
2. **有明确的国际卡种依据，且没有禁止中国发行卡的限制；实际支付仍需银行授权**
3. **商品可购买、有库存**

满足购买条件后，才按：

```
预计总成本 = 人民币商品价 + 国际运费 + 税费
```

从低到高排序。

如果运费或税费尚未核实，则明确标记“待确认”，不伪装成最终到手价。

- 后续可加入 PWA、降价提醒、历史价格曲线、收藏

---

## 7. 商业边界

BikeHunt 是**信息服务与导购导航**，不是商城。

可以做：
- 商品信息聚合
- 跨站比价
- 人民币换算
- 运费与税费估算
- 历史价格
- 降价提醒
- Affiliate 联盟链接 / 导购佣金（需清晰标注）

不做：
- 站内收款
- 站内购物车结算
- 代购代付
- 代下单
- 订单履约
- 清关代理
- 售后处理
- 自营库存

### 刷新与微信入口

服务运行期间每 **5 分钟**核对价格、每 **24 小时**核对规则，后台任务串行排队。价格或库存变化持久化为事件，打开的网站通过 SSE 接收更新；同价同库存的重复采集不会制造新消息。采集有时间间隔，不能当作上游无延迟同步。
